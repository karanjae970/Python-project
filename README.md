Simple-Societies Registration System – Project Description
Project Title

SOCIETIES REGISTRATION SYSTEM

PROJECT OVERVIEW

The Societies Registration System is a Python-based console application designed to help students register for different academic societies within an institution. The system provides a simple menu-driven interface where users can select a society, enter their personal details, and complete the registration process.

The project demonstrates the use of Python functions, dictionaries, loops, user input handling, and the match-case decision structure to create an interactive registration system.

PROBLEM STATEMENT

Educational institutions often have multiple student societies that require members to register. Manual registration can be time-consuming and difficult to organize. This system provides a basic digital solution that allows students to register quickly and efficiently for their preferred society.

OBJECTIVES
General Objective

To develop a simple computerized system for registering students into various academic societies.

Specific Objectives
- Allow students to select a society from a menu.
- Capture student information such as name and registration number.
- Confirm successful registration.
- Display the registered student's details.
- Provide a user-friendly menu for navigating between societies.# Python-project
